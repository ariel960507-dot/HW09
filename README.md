# HW09：兩場活動報名整理器 (Event Registration Organizer)

這是一個使用 Python 基礎容器（`tuple`、`list`、`set`、`dict`）與字串方法實作的活動報名資料清理與統計工具。程式能自動處理「桌遊體驗」與「電影欣賞」兩場活動的原始報名文字，進行格式統一、重複名單過濾、集合比較分析，並產出完整的報名摘要與應收費用報表。

---

## 📋 專案功能與整理規則

1. **資料清理與標準化**
   * 將原始報名字串移除所有半形空白，並統一轉換為小寫英文（例如 `" Amy"` 與 `"amy"` 視為同一人）。
   * 保留原始字串變數（`board_raw`、`movie_raw`），將拆分後的名單存入新的 `list` 以保留原始報名順序與重複紀錄。
2. **集合去重與名單比對 (`set`)**
   * 利用 `set` 自動過濾單一活動中的重複報名者（同一人於同一場次只計算一次費用）。
   * 透過集合運算子分析參與重疊度：
     * **交集 (`&`)**：同時參加兩場活動的共同參加者。
     * **聯集 (`|`)**：至少參加其中一場的總不重複名單。
     * **差集 (`-`)**：分別計算「只參加桌遊體驗」與「只參加電影欣賞」的專屬名單。
3. **名單排序與切片預覽**
   * 使用 `sorted()` 將去重後的名單依英文字母順序排列。
   * 透過串列切片 `[:2]` 擷取總名單的前兩位作為「通知名單預覽」。
4. **摘要統計與費用計算 (`dict`)**
   * 桌遊體驗每人 **120 元**，電影欣賞每人 **80 元**。
   * 區分「總不重複人數（人頭數）」與「報名人次（兩場去重人數加總）」。
   * 將所有統計數據集中存入 `summary` 字典，最終使用 `f-string` 輸出至小數點後兩位的財務摘要。

---

## 🛠️ 技術與語法限制

本專案專為 Python 基礎語法練習設計，完全採用循序結構與內建資料結構實作：
* **使用語法**：變數賦值、字串處理 (`.replace()`, `.lower()`, `.split()`)、`tuple` 拆包、`list` 切片、`set` 集合運算 (`&`, `|`, `-`)、`sorted()`、`len()`、`dict` 字典操作、`f-string` 格式化輸出。
* **無外部依賴**：不需要安裝任何第三方套件，亦未使用迴圈 (`for`/`while`)、條件判斷 (`if`/`else`) 或自訂函式 (`def`)。

## 🚀 執行方式

1. 開啟 **Google Colab** 或本地端 Python 3 環境。
2. 開啟 `event_registration.py`，將程式中的三個測試區塊分別複製到獨立的程式碼儲存格（Code Cell）中。
3. 依序執行各儲存格，即可查看三組不同情境的完整統計輸出。

## 📊 內建三組測試情境總覽

程式內已包含三組完整測試案例（皆以 `board_raw = " Amy, Ben, amy, Cora "` 為基準）：

| 測試編號 | 測試情境說明 | `movie_raw` 輸入內容 | 桌遊 / 電影人數 | 共同人數 | 總不重複人數 | 報名人次 | 總應收金額 |
| :--- | :--- | :--- | :---: | :---: | :---: | :---: | :---: |
| **測試一** | 原始基準資料 | `" ben, Dora, ERIC, ben "` | 3 / 3 | 1 | 5 | 6 | `600.00 元` |
| **測試二** | 新增一位電影參加者 | `" ben, Dora, ERIC, ben, Frank "` | 3 / 4 | 1 | 6 | 7 | `680.00 元` |
| **測試三** | 兩場去重後名單完全相同 | `" AMY, ben, CORA, amy "` | 3 / 3 | 3 | 3 | 6 | `600.00 元` |

> **註**：在「測試三」中，由於兩場活動的參加者去重後完全一致，因此「只參加桌遊者」與「只參加電影者」的差集結果皆會顯示為空串列 `[]`。
